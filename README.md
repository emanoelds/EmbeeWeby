# EmbeeWeby

EmbeeWeby é um navegador desktop personalizável para Windows, Linux e macOS, criado por Emanoel Santos para unir navegação, ferramentas e identidade visual em uma experiência própria.

## Recursos

- Abas reorganizáveis, barra de endereço com sugestões e menus de contexto.
- Favoritos com pastas, barra de favoritos, importação e exportação.
- Histórico, gerenciamento de senhas, downloads, impressão e captura de páginas.
- Temas de anime por universo e personagem, além dos temas EmbeeWeby e EmbeeSign.
- Personalização de fundos, fontes, cores, gradientes, barras e efeitos animados.
- Modos claro, escuro e do dispositivo, com opção de reduzir movimento.
- Conta de usuário e sincronização das preferências e dados compatíveis.
- Ferramentas de tradução, transmissão, leitura de QR Code e clima.
- Verificação de atualizações por escolha do usuário.

As ilustrações dos temas foram criadas para o projeto e não são imagens oficiais dos animes.
